# Reel Playlist

Reel Playlist öffnet deine Instagram-Likes oder gespeicherten Beiträge als fortlaufende Reel-Liste. Instagram selbst wird dabei nicht verändert.

## APK herunterladen

[Debug-APK herunterladen](ReelPlaylist/app-debug.apk)

Die APK ist für Android 11 oder neuer erstellt und mit einem Debug-Schlüssel signiert. Sie eignet sich zum Installieren und Ausprobieren, ist aber kein Release-Build für den Play Store.
